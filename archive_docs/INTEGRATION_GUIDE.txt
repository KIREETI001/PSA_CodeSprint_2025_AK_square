INSTALLATION STEPS
================================================================================

STEP 1: EXTRACT FILES
----------------------
Extract all files from this package, maintaining the folder structure:

  Starting_Point_Folder/
  ├── launch_dashboard.py                    <- Add this file
  ├── DETAILED_README.md                     <- Add this file
  ├── INTEGRATION_GUIDE.txt                  <- This file
  └── src/
      ├── analytics/                         <- Create this folder
      │   ├── __init__.py                    <- Add this file
      │   ├── analytics_engine.py            <- Add this file
      │   └── dashboard.py                   <- Add this file
      └── plan/
          └── job_planner.py                 <- REPLACE existing file


STEP 2: CREATE ANALYTICS FOLDER
--------------------------------
If src/analytics/ doesn't exist:

  Windows PowerShell:
    cd "path\to\your\starting_point_folder"
    mkdir src\analytics

  Linux/Mac:
    cd path/to/your/starting_point_folder
    mkdir -p src/analytics


STEP 3: COPY FILES
------------------
Copy the files to their respective locations:

  a) Copy launch_dashboard.py to root folder
  b) Copy DETAILED_README.md to root folder
  c) Copy src/analytics/__init__.py to src/analytics/
  d) Copy src/analytics/analytics_engine.py to src/analytics/
  e) Copy src/analytics/dashboard.py to src/analytics/
  f) BACKUP your existing src/plan/job_planner.py (if you modified it)
  g) Copy src/plan/job_planner.py to src/plan/ (replace existing)


STEP 4: SETUP DASHBOARD ENVIRONMENT
------------------------------------
The analytics dashboard requires PyQt5, which needs a separate environment.

Windows PowerShell:
  cd "path\to\your\starting_point_folder"
  
  # Activate your existing environment first
  .\venv\Scripts\Activate.ps1
  
  # Or if you use py_env_codesprint:
  .\py_env_codesprint\Scripts\Activate.ps1
  
  # Verify pandas is installed (should already be there)
  pip list | Select-String pandas
  
  # Create dashboard environment
  python -m virtualenv venv_dashboard
  
  # Activate dashboard environment
  .\venv_dashboard\Scripts\Activate.ps1
  
  # Install dashboard dependencies
  pip install pandas PyQt5 PyQtChart numpy python-dateutil pytz
  
  # Deactivate dashboard environment
  deactivate
  
  # Reactivate your main environment
  .\venv\Scripts\Activate.ps1

Linux/Mac:
  cd path/to/your/starting_point_folder
  
  # Activate your existing environment
  source venv/bin/activate
  # or: source py_env_codesprint/bin/activate
  
  # Create dashboard environment
  python -m virtualenv venv_dashboard
  
  # Activate dashboard environment
  source venv_dashboard/bin/activate
  
  # Install dashboard dependencies
  pip install pandas PyQt5 PyQtChart numpy python-dateutil pytz
  
  # Deactivate and return to main environment
  deactivate
  source venv/bin/activate


STEP 5: CREATE ANALYTICS LOGS DIRECTORY

================================================================================
TROUBLESHOOTING
================================================================================

ISSUE: "ModuleNotFoundError: No module named 'src.analytics'"
SOLUTION:
  - Verify src/analytics/ folder exists
  - Verify analytics_engine.py and __init__.py are in that folder
  - Check file paths are correct

ISSUE: "ModuleNotFoundError: No module named 'PyQt5'"
SOLUTION:
  - Make sure you're in venv_dashboard environment
  - Reinstall: pip install PyQt5 PyQtChart

ISSUE: Dashboard shows "No data available yet"
SOLUTION:
  - Ensure simulation (cli.py) is running in another terminal
  - Check data/analytics_logs/ folder exists
  - Wait a few seconds for data generation
  - Verify CSV files are being created

ISSUE: "Cannot activate virtual environment"
SOLUTION (Windows):
  - Run PowerShell as Administrator
  - Execute: Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
  - Try activation again

ISSUE: Jobs not being recorded
SOLUTION:
  - Check that data/analytics_logs/ directory exists
  - Verify write permissions on data/ folder
  - Check logs/ folder for error messages

ISSUE: Dashboard freezes
SOLUTION:
  - Close dashboard window
  - Verify simulation is still running
  - Restart dashboard

WHAT WAS CHANGED/ADDED
================================================================================

NEW ANALYTICS MODULES:
1. YardJobCounter
   - Tracks job completions per yard (H1-H16)
   - Records DI/LO split per yard
   - Generates yard_job_counts.csv

2. HTTimelineTracker
   - Monitors job lifecycle (created → assigned → started → completed)
   - Tracks which HT handles each job
   - Generates ht_timelines.csv

3. EmissionsCalculator
   - Calculates CO2 emissions per job
   - Uses distance and job type (DI = 0.15 kg/km, LO = 0.12 kg/km)
   - Generates emissions.csv and emissions_summary.csv

4. RouteOptimizationAnalyzer
   - Evaluates route efficiency
   - Compares actual vs optimal path length
   - Generates route_optimization.csv and route_summary.csv

5. CongestionMonitor
   - Detects traffic congestion
   - Tracks HT density per location
   - Generates congestion_events.csv and congestion_alerts.csv

DASHBOARD FEATURES:
- Real-time updates every 2 seconds
- 4 main cards:
  * HT Timelines (active/completed job counts)
  * Yard Job Counters (stacked bar chart for all 16 yards)
  * Emissions Tracker (with DI/LO progress bars showing remaining jobs)
  * Route Optimization (efficiency metrics with progress bars)
- Responsive layout
- Dark navy background for comfortable viewing
- Color-coded data (Orange=DI, Green=LO, Blue=Active, etc.)

JOB_PLANNER ENHANCEMENTS:
- Integrated analytics engine
- Polling mechanism to check for completed jobs
- Automatic tracking of:
  * Job completions (yard counter)
  * Job timelines (lifecycle events)
  * Emissions calculations
  * Route efficiency
  * Congestion detection
- No changes to core scheduling logic (just added tracking)

================================================================================
KEY METRICS EXPLANATION
================================================================================

1. YARD JOB COUNTS
   - Shows how many jobs completed at each yard
   - Helps identify yard utilization balance
   - DI jobs (red bars) vs LO jobs (yellow bars)

2. HT TIMELINES
   - Active: Jobs currently being executed
   - Completed: Jobs that finished
   - Tracked: Total unique jobs in system

3. EMISSIONS
   - DI emissions: 0.15 kg CO2 per km traveled
   - LO emissions: 0.12 kg CO2 per km traveled
   - Progress bars show remaining jobs (deplete to zero)
   - Counter shows "X jobs" remaining for each type

4. ROUTE OPTIMIZATION
   - Efficiency = (optimal_distance / actual_distance) × 100%
   - Optimal routes: Routes with efficiency > 90%
   - Higher efficiency = better route planning

5. CONGESTION
   - Detected when multiple HTs occupy same grid location
   - Severity levels: LOW, MEDIUM, HIGH, CRITICAL
   - Dashboard shows popup alerts for HIGH/CRITICAL

================================================================================
INTEGRATION WITH YOUR ALGORITHM
================================================================================

The analytics system is TRANSPARENT to your optimization algorithm.

You can:
✓ Modify scheduling logic in job_planner.py
✓ Change route planning strategies
✓ Implement new optimization techniques
✓ Adjust job prioritization

The analytics will automatically track your changes without requiring
any modifications to the analytics code itself.

The analytics are called at these key points:
1. When a job is assigned: create_timeline()
2. When planning a route: calculate_emissions() + analyze_route()
3. When a job completes: record_job_completion() + complete_job_timeline()
4. Periodically: update_congestion()

All these calls are already in place in job_planner.py.
